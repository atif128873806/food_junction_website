# Implementation scope — current light-site delivery

The user's 2026-10-18 direction supersedes the earlier immersive dark proposal. The active target is a simple white restaurant website with red accents, native system typography, authentic Tandoori Junction menu-proof photos and a full photo-led menu without search.

## Delivered

- Home, Menu, Our Story, Catering and Visit Us pages.
- All 12 PDF menu groups, 18 leaf headings and 169 transcribed entries, including source descriptions, printed amounts/variants and review notes.
- The menu category selector renders only the chosen group, keeping each original group available through a shareable `?category=` link.
- Category-level photography from the menu proof, responsive derivatives, original Tandoori Junction logo and source provenance.
- Expanded full-width homepage food-image hero and restrained homepage-only GSAP motion with reduced-motion support.
- Dine-in, takeout and catering service paths; visit address/phone and directions based on the printed proof.

## Excluded

No reservation/booking policy, ordering provider, admin dashboard, database, payment/cart, fabricated hours or external deployment. Do not add these without confirmed requirements. Owner confirmation of printed prices, options, address/phone, hours and photo rights remains necessary before publication.

The source PDF supplies category banners rather than an individually verified picture for every dish. The site displays each banner beside its menu group and preserves all dish names and details below it. See `docs/reviews/COMPLETION-REVIEW.md` and `docs/content/PAGE-ASSETS.json` for review and provenance.
