# Homepage — current light direction

Status: implement per SRC-LIGHT-008. The user explicitly replaced the previous immersive dark eight-chapter composition. Keep the site direct, food-led and easy to scan.

1. **Header:** original logo on white; links to Menu, Our Story, Catering and Visit Us; a single red View Menu action. Mobile uses a compact native disclosure and a clear Menu link.
2. **Hero:** full-width, generously tall hero with a real Tandoori Junction food image from the menu PDF as the background. Keep the whole site light: place the short restaurant heading, factual Markham cuisine/service line and Menu/Visit actions in a solid white panel with dark system text and a red action. Image fills the complete hero width; use a focal crop that keeps the tandoori plate visible on desktop and mobile. Do not add a dark page treatment or unapproved slogan.
3. **Food:** a small row of real PDF-sourced images for tandoori, street-food and curry categories. Apply restrained GSAP entry/reveal motion to these photos and the hero image. The food remains visible if JavaScript is unavailable and motion is skipped for reduced-motion preference.
4. **Services:** simple three-column text links for dine-in, takeout and catering; stack into three rows on mobile.
5. **Visit:** printed address and phone, a call-for-hours instruction, address-based directions link and final Menu action.

The homepage does not repeat the complete menu; it helps diners reach it. Keep white and near-white surfaces, red used sparingly for action, modest heading sizes, system sans-serif and generous but practical spacing. The full-width food image is the only cinematic element; the content stays easy to read. No fabricated history, reviews, awards, staff, booking, online ordering, delivery promise or opening hours. A is historical only.
